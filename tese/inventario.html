O que é um checkpoint

Um treino é como um filme, e um checkpoint é uma fotografia dos pesos num instante. Os pesos mudam a cada lote de imagens; se você só olhasse o modelo no fim, veria o destino e nada do trajeto. Então, de tempos em tempos, o código pausa e anota o valor de todos os pesos naquele momento.

São cerca de 90 checkpoints por run, ao longo de 100 épocas — uma época é uma passada completa pelos dados de treino. Em cada checkpoint o código calcula LMC e SampEn dos quatro grupos e grava uma linha no metrics.csv. Cada checkpoint é um ponto na curva: é assim que as trajetórias dos gráficos são construídas.

Por que isso limita o que ainda dá para fazer
